## Основа дизайн-системы (первый эпик)

### Переменные (`00 Tokens`)
Источник правды — `tokens.css` (U23). У каждой переменной WEB code syntax = `var(--<имя>)`. Имя в Figma — это имя CSS без `--`, части разделены `/` (DESIGN §16.2): `color/text/muted` ↔ `--color-text-muted`, `space/4` ↔ `--space-4`. Scopes заданы явно: фон, текст, обводка, отступ, радиус, размер шрифта. У `base/*`, `z/*`, `duration/*`, `font/family` и `font/mono` scopes пустые, переменные скрыты из пикеров.

| Коллекция | Режимы | Переменные |
|---|---|---|
| `color` | **`light`, `dark`** | 19 семантических §5. Алиасы на `base/*`, кроме `-bg` и `overlay`: у них значения заданы сразу (`overlay` — чёрный 40% / 60%) |
| `base` | `value` | 23 цвета §4 |
| `component` | `value` | §7.1: `button/*` (9), `clock/*` (4), `judgement/*` (3) — алиасы на `color/*`, поэтому меняются с темой. §6: `board/light`, `board/dark` (brown, значения blue и green — в описании), `board/last-move`, `board/dest`, `board/selected` |
| `space` | `value` | `space/1…8` = 4…64 |
| `radius` | `value` | `radius/s` 4, `radius/m` 8, `radius/full` 999 |
| `font` | `value` | `font/family`, `font/mono` (строки); `font/size/s|m|l|xl` = 14/16/20/24; `font/size/clock` = 32 (40 при ≥ 768 px — в описании) |
| `layout` | `value` | `container-max` 1200, `board-max` 640, `side-panel` 320, `header-height` 48, `clock-height` 48, `touch-target` 44 |
| `border` | `value` | `border/width` 1, `focus/width` 2 |
| `z`, `duration` | `value` | `z/header|dialog|toast` 10/100/200; `duration/fast|move` 120/200 |

Тема меняет только семантический уровень (§3, §5). Тёмный фрейм получает режим `dark` коллекции `color` (explicit mode). Компонентные токены идут через алиасы и потому перекрашиваются сами.

Не перенесено в переменные: `--board-check` (radial-gradient) — переменные Figma не хранят градиенты; `--shadow-m` — сделан стилем эффекта `shadow/m`.

### Стили
- Эффект `shadow/m` — две тени §4 (в тёмной теме не применяется).
- Текст: Inter как замена системного стека (U4), размер привязан к `font/size/*`, межстрочный 140%. Стили: `text/s`, `text/m`, `text/m-strong`, `text/l`, `text/l-strong`, `text/xl-strong`, `text/clock`. Начертания (Regular / Semi Bold) в DESIGN не заданы — «Открытые вопросы», п.3.

### Указания для T-5 (frontend)
- **`logo-knight.svg`** — по `Logo` / знак н: экспорт вектора `27:108` (или фрейма `mark` варианта `4:7`).
  - `viewBox="0 0 64 64"` — исходная сетка знака, в `Logo` он масштабирован до 28 px.
  - Один `<path>` с `fill="currentColor"`, без `stroke` и градиентов. Цвет задаёт CSS: `color: var(--color-accent)`.
  - В разметке `aria-hidden="true"` (см. `lobby`, «Доступные имена»).
- **`favicon.svg`** — по `favicon` (`27:217`) / знак о, `viewBox` 32 × 32, один `<path>`.
  - `currentColor` во вкладке браузера не наследуется. Поэтому цвет в файле задаётся значениями токена: `--color-accent` light (`base/blue/600`) и dark (`base/blue/400`) через `@media (prefers-color-scheme: dark)` внутри SVG.
  - Литерал цвета в SVG — значение токена из `tokens.css`, не новый токен. Как его подставлять (вручную или сборкой) — решает frontend / architect.
- Плавный серп под челюстью — единственная кривая в контуре. При экспорте не упрощать его до прямых.

Самопроверка по скриншотам:
- **64 / 28 px** — у н и о читается именно шахматный конь: голова, грива-грани, воротник, цоколь. Морда определённая, строгая, без «рожи».
- **16 px:**
  - о узнаётся сразу — силуэт фигуры на доске;
  - у н фигура около 10 px, но «C + фигура-конь» узнаётся, цоколь виден.
- Тёмная тема: перекрашивается через `color/accent`, читается так же.
