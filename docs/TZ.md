# ТЗ: онлайн-платформа для игры в шахматы (Open Beta)

Версия 0.1 · Nov 4, 2026 · @Ivan

## 1. Общие сведения

Платформа — веб-сервис, где игроки входят через Google, находят соперника автоматически или создают свою игру и получают рейтинг Glicko-2 в общей таблице лидеров. Цель открытой беты — проверить ядро продукта на реальной аудитории и собрать обратную связь перед публичным запуском.

**Целевой масштаб беты:**

| Параметр | Значение | Запас для расчёта нагрузки |
| --- | --- | --- |
| Зарегистрированные пользователи | до 1 000 | 3 000 |
| Активные пользователи (в день) | \~100 | 300 |
| Одновременно онлайн (пик) | 30–50 | 150 |
| Одновременные партии (пик) | 15–25 | 75 |

**Глоссарий:**

- **Вызов (своя игра)** — партия, которую игрок создаёт с выбранными параметрами; соперник принимает её из списка открытых игр или по ссылке.
- **Подбор (матчмейкинг)** — автоматический поиск соперника с близким рейтингом в выбранном контроле времени.
- **Контроль времени** — запас времени на партию + добавление за ход, например 3+2 (3 минуты + 2 секунды за ход).
- **Рейтинговая / товарищеская партия** — первая влияет на рейтинг, вторая нет.
- **Glicko-2** — система рейтинга, учитывающая не только силу игрока, но и надёжность оценки (RD).

## 4. Функциональные требования

### 4.1. Вход и регистрация (Google OAuth 2.0)

1. Единственный способ входа — кнопка «Войти через Google» (OpenID Connect).
2. При первом входе создаётся аккаунт; сохраняются Google ID (sub), e-mail, имя, аватар.
3. После первого входа игрок выбирает уникальный ник: 3–20 символов, латиница, цифры, «\_» и «-»; ник можно сменить 1 раз.
4. Игрок принимает правила платформы и политику конфиденциальности (галочка при первом входе).
5. Сессия живёт 30 дней; есть кнопка «Выйти» и «Выйти со всех устройств».
6. Удаление аккаунта по запросу из профиля: партии остаются в истории с ником «удалённый игрок».

### 4.2. Профиль игрока

- Ник, аватар из Google, страна (необязательно), дата регистрации.
- Рейтинг по каждому контролю (пуля, блиц, рапид) и отметка «предварительный», пока RD > 110.
- Статистика: всего партий, победы / ничьи / поражения, процент побед.
- График изменения рейтинга по контролю.
- Список последних партий со ссылками на просмотр.
- Настройки: язык (RU/EN), тема (светлая/тёмная), звук, вид доски и фигур, автоферзь, подтверждение хода на мобильном.

### 4.3. Создание своей игры (вызов)

1. Игрок выбирает: контроль времени (из пресетов или свой), рейтинговая / товарищеская, цвет (белые / чёрные / случайно).
2. Вызов бывает двух видов:
   - **Открытый** — появляется в лобби в списке открытых игр; принять может любой игрок.
   - **По ссылке** — генерируется ссылка, которую игрок отправляет другу; другие вызов не видят.
3. Опционально: ограничение по рейтингу соперника (например, ±300).
4. Вызов живёт до принятия, отмены создателем или 30 минут без принятия.
5. У одного игрока одновременно не более 1 открытого вызова и 1 активной партии.

### 4.4. Автоподбор соперника

1. Игрок выбирает контроль времени и нажимает «Найти игру»; подбор всегда рейтинговый.
2. Сначала ищется соперник в пределах ±100 рейтинга; диапазон расширяется на 50 каждые 5 секунд до ±500.
3. Если никого нет через 60 секунд — предложить создать открытый вызов.
4. Цвета назначаются так, чтобы чередовать их для игрока.
5. Не сводить одних и тех же игроков более 3 раз подряд.

### 4.5. Пресеты контроля времени

| Категория | Пресеты |
| --- | --- |
| Пуля | 1+0, 1+1, 2+1 |
| Блиц | 3+0, 3+2, 5+0, 5+3 |
| Рапид | 10+0, 10+5, 15+10, 30+0 |

Категория своего контроля определяется по ожидаемой длительности: базовое время + 40 × добавка. До 179 с — пуля, 180–479 с — блиц, от 480 с — рапид (верхний предел своего контроля — 60+30).

### 4.6. Партия

- Доска с ходом перетаскиванием и кликом; подсветка последнего хода, шаха, допустимых ходов.
- Все правила шахмат проверяются на сервере: рокировка, взятие на проходе, превращение пешки.
- Часы считаются на сервере; клиент только отображает. Компенсация задержки сети (lag compensation) до 1 с на ход.
- Нотация ходов (SAN), навигация по ходам во время партии.
- Кнопки: сдаться, предложить ничью, отменить ход (только с согласия соперника, только в товарищеской), отменить партию (до 2-го хода каждой стороны).
- Если игрок не сделал первый ход за 30 с — партия отменяется без влияния на рейтинг.
- Автоматическое завершение: мат, пат, троекратное повторение, правило 50 ходов, недостаток материала, флаг (с учётом недостатка материала у соперника).
- Разрыв соединения: таймер переподключения 60 с (не больше остатка на часах); после него — победа соперника с возможностью отказаться от неё (ничья / отмена).
- Звуки хода, взятия, начала и конца партии, уведомление о низком времени.
- Зрители могут смотреть текущие партии по ссылке (без задержки в бете, т.к. нет турниров с призами).

### 4.7. Рейтинг (Glicko-2)

- Отдельный рейтинг для каждой категории: пуля, блиц, рапид.
- Начальные значения: рейтинг 1500, RD 350, волатильность 0,06; τ = 0,5.
- Пересчёт сразу после каждой рейтинговой партии (по методу Lichess, без периодов).
- Отображение: рейтинг округляется до целого; изменение (+12 / −9) показывается после партии.
- Рейтинг считается предварительным при RD > 110 — отмечается знаком «?».
- Отменённые партии и товарищеские игры на рейтинг не влияют.

### 4.8. Таблица лидеров

- Вкладки: пуля, блиц, рапид.
- Топ-100 по рейтингу; колонки: место, ник, рейтинг, число партий, изменение за 7 дней.
- В таблицу попадают только игроки с непредварительным рейтингом (RD ≤ 110), сыгравшие хотя бы 1 партию за последние 14 дней и не забаненные.
- Строка «Ваше место» внизу для залогиненного игрока.
- Обновление — не реже раза в 5 минут (кэш).

### 4.9. История партий и разбор

- Список партий игрока с фильтрами: контроль, результат, соперник, дата.
- Просмотр завершённой партии: навигация по ходам, переворот доски, время на каждый ход.
- Экспорт / копирование PGN и FEN текущей позиции.
- Разбор движком: Stockfish (WASM) в браузере игрока — оценка позиции, лучшая линия, график оценки по партии, отметки ошибок (неточность / ошибка / зевок).
- Анализ в браузере не нагружает сервер; серверный анализ — после беты.

### 4.10. Жалобы и модерация

- Кнопка «Пожаловаться» в профиле и после партии: причина (читерство, оскорбительный ник, игра на время/саботаж), комментарий.
- Жалобы попадают в очередь админ-панели.

### 4.11. Админ-панель

- Поиск игрока по нику / e-mail; карточка: партии, рейтинги, жалобы.
- Действия: бан (с причиной и сроком), разбан, принудительная смена ника, обнуление рейтинга, аннулирование результата партии с откатом рейтинга обоим.
- Очередь жалоб со статусами: новая, в работе, закрыта.
- Дашборд: зарегистрированные, DAU/WAU, партии за день, игроков онлайн.
- Журнал действий администраторов.

### 4.12. Обратная связь беты

- Кнопка «Сообщить об ошибке / идея» на каждой странице: текст, скриншот (опционально), автоматически — URL, браузер, ID партии.
- Пометка «Бета» в шапке сайта.

## 7. Этапы, приёмка и метрики беты

**Этапы разработки** (сроки уточняются, см. открытые вопросы):

1. Прототип: вход через Google, доска, партия по ссылке между двумя игроками, серверные часы.
2. Ядро: лобби, открытые вызовы, автоподбор, рейтинг Glicko-2, профиль.
3. Обвязка: история партий, разбор Stockfish, таблица лидеров, RU/EN, мобильная вёрстка.
4. Админ-панель, жалобы, форма обратной связи, мониторинг, бэкапы.
5. Закрытое тестирование (10–20 человек), нагрузочный тест на 150 игроков онлайн.
6. Открытая бета: приглашения / открытая регистрация до лимита 1 000.

**Критерии приёмки беты:**

- [ ] Новый игрок входит через Google и начинает партию через автоподбор менее чем за 1 минуту (при наличии соперника).
- [ ] Вызов по ссылке открывается у друга и стартует партию в 2 клика.
- [ ] Все правила шахмат и окончания партии проходят набор тестов (включая рокировку, взятие на проходе, превращение, пат, повторение).
- [ ] Часы не расходятся с серверными больше чем на 0,5 с; флаг фиксируется сервером.
- [ ] Рейтинг пересчитывается по Glicko-2 и сверяется с эталонной реализацией на тестовом наборе партий.
- [ ] Таблица лидеров отражает правила попадания из п. 4.8.
- [ ] Партия восстанавливается после перезагрузки страницы и после перезапуска сервера.
- [ ] Сайт корректно работает на телефоне 360 px и на десктопе, на RU и EN.
- [ ] Нагрузочный тест: 150 онлайн / 75 партий, задержка хода p95 ≤ 150 мс.
- [ ] Администратор может забанить игрока и аннулировать партию с откатом рейтинга.

**Метрики, которые отслеживаем в бете:**

| Метрика | Цель |
| --- | --- |
| Регистрации | до 1 000 |
| DAU | \~100 |
| Доля новичков, сыгравших ≥ 1 партию в первый день | ≥ 70% |
| Удержание D7 | ≥ 25% |
| Среднее время ожидания подбора | ≤ 20 с |
| Доля партий, прерванных из-за сбоев | ≤ 1% |
| Критические баги за неделю | 0 открытых дольше 48 ч |

## 8. Открытые вопросы

- [ ] Сроки и бюджет беты; кто разрабатывает (своя команда, подрядчик, один разработчик)?
- [ ] Основная аудитория — Россия или международная? От этого зависят хостинг, 152-ФЗ и доступность входа через Google.
- [ ] Название, домен, логотип, фирменные цвета.
- [ ] Бета открытая для всех или по инвайтам / листу ожидания? Что делать после 1 000 регистраций?
- [ ] Нужны ли друзья / подписки и приглашение конкретного игрока по нику (а не только по ссылке)?
- [ ] Подтверждаем, что чат в партии не нужен? Если нужен — только быстрые фразы или свободный текст с фильтром?
- [ ] Какой стек привычнее команде (Node.js / Go / Python)?
- [ ] Сохраняем ли рейтинги и аккаунты после беты или обнуляем рейтинги при запуске?
- [ ] Кто модерирует жалобы и как быстро?
- [ ] Нужны ли e-mail-уведомления (например, «ваш вызов приняли»)?
