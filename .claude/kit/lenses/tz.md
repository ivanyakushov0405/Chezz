# Линза tz — соответствие ТЗ и бизнесу
- Запусти `.claude/kit/scripts/tz-coverage.sh --tz docs/TZ.md <документ>`: какие разделы ТЗ документ упоминает. Сверь с разделами ТЗ, которые к нему относятся (`section.sh --toc docs/TZ.md 3`), — **не читай ТЗ целиком**, только непокрытые подозрительные разделы через `section.sh`.
- Нет противоречий ТЗ; нет требований сверх ТЗ без пометки «по умолчанию».
- Ссылки `ТЗ §N.N` ведут на существующие разделы и совпадают по смыслу (выборочно, 3–5 ссылок).
- Ограничения из `docs/setup/BUSINESS.md` учтены: сроки, стек, команда, «вне этапа».
