# Линза agentability — агент сможет работать без догадок и без лишних токенов
- Нет плейсхолдеров и «уточнить позже» в правилах, по которым агент будет действовать.
- Правило проверяемо: тестом, линтером, скриптом или пунктом чек-листа ревью.
- Примеры из домена проекта, без примеров из чужого домена.
- **Стоимость.** Запусти `.claude/kit/scripts/token-report.sh <документ>`:
  - неделимый раздел больше бюджета — 🟠 «разбить»: агенты читают разделами через `section.sh`;
  - для F8: агент больше бюджета (по умолчанию ≈1500 токенов) — 🟠; правила в агенте должны быть ссылками на разделы, а не копиями.
- Для F8 дополнительно: `.claude/kit/scripts/check-zone.sh --validate` без ошибок; в агентах нет `{{`; агенты читают документы через `section.sh`, а не целиком; ответы агентов оркестратору короткие (детали — в файлах).
