Вход от человека: $ARGUMENTS

## Перед началом
- `.claude/profile.md` есть? Нет — ⛔ «сначала `/setup`».
- `docs/TZ.md` и документы основ из профиля (раздел «Документы») существуют? Нет — ⛔ сообщи.
- Трекер — из профиля, раздел «Трекер». Если `jira`, проверь, что инструменты Atlassian MCP доступны; нет — ⛔ предложи подключить или работать с файлами.

## Вызов агента — всегда так
1. `T=$(bash <(git show HEAD:.claude/kit/scripts/check-zone.sh) begin <зона>)` — токен держи в своём контексте, не в файлах.
2. Вызов агента.
3. `bash <(git show "${T%%.*}":.claude/kit/scripts/check-zone.sh) end <зона> --since "$T"`. Нарушение → `git restore --source="${T%%.*}" -- <пути>`, новые файлы удали, верни агенту со списком (это раунд).
4. +1 в `log.md`: агент, модель.

## Шаги
1. `git switch main && git switch -c docs/roadmap`.
2. `analyst`, режим roadmap (зона `roadmap`), с пожеланиями человека.
3. `architect`, режим roadmap (зона `architect`). Его замечания к ROADMAP передай `analyst` (режим roadmap, «учти замечания архитектора»).
4. ⛔ **Утверждение**: таблица эпиков, порядок, что параллельно, список ADR, открытые вопросы. Правки — снова через `analyst` или `architect`.
5. После «да»: `git add docs/ROADMAP.md docs/adr/` → `docs(roadmap): epics and ADRs`.
6. **Jira** (если трекер `jira`): для каждого эпика — Epic в проекте из профиля; в описании — разделы ТЗ, зависимости, ссылка на ROADMAP в репозитории. Ключи эпиков допиши колонкой «Трекер» в ROADMAP.md (отдельный коммит). Содержание остаётся в репозитории; в Jira — статус и ссылки.
7. Скажи человеку, с какого эпика начинать.
